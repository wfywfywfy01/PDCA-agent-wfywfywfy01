# 工作台设计规范（对标与决策）

> 本文记录 2026-09-23 界面重构的**对标来源**与**落地规则**，避免后续再凭感觉改。
> 变更入口：`apps/web/src/styles/tokens.css`（令牌）、`apps/web/src/styles/ui.css`（组件层）、
> `apps/web/src/components/AppNav.vue`（外壳）、`apps/web/src/components/CommandPalette.vue`。

## 一、对标对象（为什么学它们）

| 对标 | 学什么 | 应用点 |
|------|--------|--------|
| **Ant Design Pro** | 中后台标准布局：可折叠 sider（图标 + 分组菜单）+ 顶栏（面包屑/搜索/用户）+ PageContainer（标题 + 操作区） | 外壳结构、分组导航、页面标题区 |
| **Stripe / Mixpanel / Datadog / Retool**（B2B 数据密集型模式） | 「数据即界面」、可扫描性优先、过滤条 + chips、粘性表头、行内操作、主从布局 | 过滤条、数据表、详情抽屉 |
| **Linear** | 高密度、键盘优先（⌘K）、克制的描边与低饱和配色、紧凑行高 | 命令面板、34px 行高、单一强调色 |

## 二、布局规范（复刻目标）

```
┌──────────────────────────────────────────────┐
│ 顶栏：面包屑 │ 搜索(Ctrl K) │ 角色 │ 用户      │  ← 52px，固定
├──────────┬───────────────────────────────────┤
│ 侧边栏    │ 页面标题 + 操作区                  │
│ 232px    │───────────────────────────────────│
│ ↔60px    │ 过滤条（sticky，chips + 计数 + 清除）│
│ 分组菜单  │───────────────────────────────────│
│ 图标+文字 │ 主内容（表格/看板/详情，全宽）      │
└──────────┴───────────────────────────────────┘
```

- 侧边栏 232px ↔ 60px（图标轨），状态存 `localStorage.pdca.shell.collapsed`；≤900px 改为抽屉。
- 顶栏固定 52px；内容区左留白由 `body.shell-ready` 控制（页面里的 `<main class="page">` 是外壳的兄弟节点，因此用 body 类而不是包裹组件）。
- 主内容**全宽**（`.page` 在 shell 模式下 `max-width: none`）；表格滚动区 `max-height: calc(100dvh - 300px)`，表头 sticky。

## 三、组件规则

| 组件 | 类名 | 规则 |
|------|------|------|
| 页面标题 | `.page-head` | 标题 + 副标题（口径说明）+ 右侧操作；一页一个 h1 |
| 过滤条 | `.filterbar` + `.chip-filter` | 粘在顶栏下方；chip 激活用填充态；右侧放刷新/新建 |
| 数据表 | `.table-shell > .table-scroll > table.grid` | 粘性表头、行 hover、行内操作默认 0 透明度 hover 显现、数字右对齐 + tabular-nums、长文本 `.truncate` |
| 状态 | `.status` + `.ok/.warn/.danger/.info/.idle` | **全站只有这 5 态**；圆点 + 文案，不靠颜色单独表意 |
| 主从详情 | `.drawer-backdrop` + `.drawer` | 记录详情/只读信息用右侧抽屉；短表单与确认才用弹窗 |
| 命令面板 | `.palette` | Ctrl/⌘ + K 唤起，↑↓ 选择、Enter 打开、Esc 关闭 |
| 空态/加载/错误 | `.empty-state` / `.skeleton-*` / `.alert` | 空态必须给一个明确的下一步动作；错误必须可重试 |

## 四、视觉规则（硬性）

1. **无渐变、无重阴影**；层级只靠表面色阶 `--surface-1/2/3` 与 1px 描边 `--line`。
2. **单一强调色**（`--info` 蓝）；状态色只用于状态，不做装饰。
3. 间距只用 4px 刻度（`--sp-1..10`）；圆角只用 `--radius-sm/md/lg/xl`。
4. 文本三层：`--text-1`（主）/ `--text-2`（次）/ `--text-3`（弱）；正文对比度 ≥ 4.5:1。
5. 交互反馈 ≤200ms，只动 `background-color`/`color`/`transform`/`opacity`；点按目标 ≥24px（行内图标按钮 26px）。
6. 数字一律 `.num`（tabular-nums）；表格数字右对齐；大数缩写、悬停显示原值。
7. **权限不足的操作灰显 + tooltip 说明**，不要整块隐藏（用户需要知道功能存在）。
