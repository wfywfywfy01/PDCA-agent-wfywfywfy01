1. 执行摘要
《签单手账》提出了一套以“红桃→梅花→方块→黑桃”四维度驱动的完整销售操作系统，涵盖从认知策略、关系沟通、执行落地到成交转化的全链路。SignalSeller 将这套方法论抽象为五个协同 Agent，用 AI 替代重复劳动，让销售团队专注于高价值的人际互动。
核心思路
书中的核心转变是：从“推销”转向“销售”——即从“我要把东西卖给你”转变为“帮你买到你需要的解决方案”。Agent 的设计逻辑完全遵循这一原则：不是暴力群发，而是精准触达、价值前置、自然推进。

3. 系统架构
3.1 五 Agent 协同拓扑
系统采用“中心调度 + 单责执行”架构。CommandCenter 作为大脑，其余四个 Agent 各司其职，通过事件总线异步协同。

3.2 数据流转全景
全链路数据流如下：
SignalHunter 抓取多渠道线索 → 写入线索池 (raw_leads)
ProfileBuilder 消费 raw_leads → 构建客户画像 + ABCD分级 → 写入 customer_profiles
OutreachCrafter 读取 customer_profiles → 用FABE生成个性化触达内容 → 写入 outreach_queue
FollowUpOrchestrator 监听客户交互事件 → 触发多轮跟进状态机 → 输出跟进动作
CommandCenter 全局监控 → 异常预警 + ROI复盘 + ABCD调级建议

7. 核心工作流详解
7.1 新线索全自动处理流
SignalHunter 从 LinkedIn/展会/社群等渠道发现新线索
ProfileBuilder 自动构建客户画像：行业 + 规模 + 职位 + 潜在痛点
ProfileBuilder 执行 ABCD 评分，确定初始级别和跟进频率
OutreachCrafter 根据画像生成 FABE 个性化触达内容
FollowUpOrchestrator 启动三轮触达状态机，第1轮发送价值型内容
客户回复/不回复 → 状态机自动流转到下一阶段
CommandCenter 全程监控，异常时自动介入调整策略
7.2 转介绍裂变闭环
对应书中小王篇「客户裂变——推荐者养成三阶段」：
成交后自动触发“峰值体验”设计：发送使用指南 + 感谢信 + 超额交付资料
售后回访时自动插入推荐话术：“感谢+价值+低门槛”公式
收到推荐后 24h-48h-72h 闭环管理：联系→反馈→感谢推荐人
阶梯式激励自动升级：推荐1个/3个/5个对应不同奖励
推荐成交数据回流 CommandCenter，优化推荐率指标

10. 附录：Prompt 模板示例
A. FABE 内容生成 Prompt
你是一位 B2B 销售文案专家。根据以下客户画像和产品信息，用 FABE 法则生成一封触达邮件。
规则：
1. F(功能)→A(优势)→B(利益)→E(证据) 四层递进
2. B层必须用“当…时，你不需要…”的场景化语言
3. E层必须包含具体数据或客户名称
4. 第一句话必须包含“你”字，让客户感觉和他有关
5. 结尾用“零压力”行动指令，不说“买”“下单”
6. 全文≤150字
B. SPIN 问题库生成 Prompt
你是一位销售教练。根据以下客户行业和产品信息，生成一套 SPIN 问题库。
规则：
1. S(现状)问题 3个，只问事实不评判，全程≤45分钟
2. P(难点)问题 3个，用“有没有…？”开头
3. I(暗示)问题 3个，用客户自己的话延展后果，连续追问2-3层
4. N(需求)问题 2个，客户说“有帮助”后立即转方案
5. 每个问题附带“客户可能回答”和“下一步动作”
C. ABCD 评分 Prompt
你是一位客户分级分析师。根据以下客户信息，评定 ABCD 级别。
评分规则：
- 价值维度(0-50分)：客单价(20) + 复购潜力(15) + 转介绍可能(15)
- 意向维度(0-50分)：需求明确度(20) + 决策进度(15) + 沟通反馈(15)
分级标准：
A类: 两维度均≥35分 → 重点攻克
B类: 价值≥35 AND 意向<35 → 长期培育
C类: 价值<35 AND 意向≥35 → 快速成交
D类: 两维度均<35 → 批量维护
输出格式: JSON {grade, value_score, intent_score, reason, follow_up_frequency}

书中原则 | Agent硬约束实现
先听后说 | 不在客户未回复时连续发送多条消息，必须等待或触发下一轮
先认后解 | 所有触达内容以价值前置，不使用压力型话术
不争对错 | Agent禁止生成攻击竞品的内容，只说自己的好
不贬竞品 | 竞品对比只用差异化表述，不用贬低性词汇
不空承诺 | 只使用已验证的数据和案例作为证据
