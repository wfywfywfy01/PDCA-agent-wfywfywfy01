# SOP-07 社媒获客（Safiran 复刻）

## 1. 目的

把伊朗 Safiran 已验证的 IG → WhatsApp 私域路径，标准化给新代理。

## 2. 触发

代理签约后 7 日内启动；或月台数低于台阶时作为增长动作。

## 3. 角色

| 角色 | 职责 |
|------|------|
| Sana | 拆解范本、波斯语培训、《社媒 Playbook》 |
| 代理 | 本地 KOL、VIP 上门、现金/换汇结算 |
| 总部 | 素材库、产品培训、维修 SLA 话术 |
| BD Lead | 周报复核 |

## 4. 可复制观察（范本要点）

| 维度 | 动作 |
|------|------|
| 视觉 | 统一产品图 + 当地语言定价咨询入口 |
| 获客 | 评论询价 → 私信 → WhatsApp（「评论触发私信」SOP） |
| 转化 | 强调官方 + 保修 + 以旧换新；高客单低频 |
| 量级参照 | Safiran 15–30 台/月（硬锚点，非承诺他国复制量） |

## 5. 步骤（签约后前 30 天）

| 天 | 动作 | 产出 |
|----|------|------|
| D1–3 | 账号视觉对齐总部模板；绑定客服 WhatsApp | 账号就绪 |
| D4–7 | Sana/总部培训：Story、询价话术、售后话术 | 培训签到 |
| D8–14 | 上线内容日历（每周 ≥4 条 Feed/Story） | 日历表 |
| D15–30 | 跑「评论→私信→WhatsApp」；建询价表 | 周销售报表 |
| 每周五 | 提交周报（模板 T03） | 漏斗数字 |

## 6. 分工红线

| 必须由代理做 | 总部/Sana 做 |
|--------------|--------------|
| 本地 KOL 合作 | 素材库 |
| VIP 上门 | 产品培训 |
| 现金/换汇/分期方案 | 维修 SLA 话术 |
| 当地节日创意 | 内容日历框架 |

## 7. 产出物

- 《社媒 Playbook》当地语言版  
- 内容日历（月）  
- [`templates/T03_周销售报表.md`](templates/T03_周销售报表.md)

## 8. 验收标准（首月）

- [ ] 官方/授权账号上线且视觉统一  
- [ ] 询价→WhatsApp 转化链路跑通（抽样 ≥10 条）  
- [ ] 周报连续 4 周提交  
- [ ] 话术含保修/以旧换新，无虚假「全球联保」表述

## 9. 异常分支

| 情况 | 动作 |
|------|------|
| IG 受限/封禁 | 启用 Telegram / 本地平台备份；不中断 WhatsApp |
| 只有曝光无询价 | 加价格锚点与 CTA；审核是否错客群 |
| 代理把社媒全甩给总部 | 书面重申红线；计入代理考核 |
