# SOP-04 落位选址

## 1. 目的

用统一评分选出主店，避免「最大 Mall = 最好」的误判。

## 2. 触发

看店、谈招商、迁址（如科威特离开 Al Hamra）时。

## 3. 角色

BD Lead（审批）· 国别 BD（踩点）· Analyst（算分）· 售后（评估维修空间）

## 4. 输入

- [`tables/02_分国落位速查.md`](tables/02_分国落位速查.md)  
- [`templates/T02_选址评分表.md`](templates/T02_选址评分表.md)  
- 租金意向、面积图纸、邻居清单

## 5. 硬性门槛（任一不满足 → 不进主店候选）

| # | 门槛 |
|---|------|
| 1 | 面积建议 ≥80㎡（体验+试机+贵宾；伊拉克首店 80–120㎡） |
| 2 | 可做品牌独立门头或清晰精品形象（非纯柜台） |
| 3 | 邻居含腕表/珠宝/硬奢至少一类（或可论证 UHNWI 动线） |
| 4 | 租金落在参数表假设区间可解释（或代理书面接受超支） |
| 5 | 科威特：主店不得选 Al Hamra Tower |
| 6 | 阿曼：优先 Mall of Oman L3 或 Qurum；无 LV 不代表无机会 |

## 6. 评分维度（每项 1–5，权重如下）

| 维度 | 权重 | 观察要点 |
|------|------|----------|
| UHNWI / 高端客群密度 | 25% | Prestige 区、老钱街区、沙特周末车牌 |
| 奢侈品邻居浓度 | 20% | IWC/Cartier/LV/AP 等同层或同区 |
| 客流质量（非唯总量） | 15% | 转化潜力；巴林看 Causeway |
| 可达性与停车/礼宾 | 10% | VIP 接待便利 |
| 租金与合同弹性 | 15% | 月租、租期、退出 |
| 售后/仓储可行性 | 10% | 基础维修空间 |
| 代理运营匹配 | 5% | 是否其已有同场经验 |

**通过线：** 加权得分 ≥3.5，且硬性门槛全过。  
**主店：** 得分最高且 BD Lead 签字。备选保留 1 个。

## 7. 分国快速规则

| 国家 | 规则 |
|------|------|
| 伊朗 | 3 城覆盖 > 同城多开；第 4 店默认不批 |
| 伊拉克 | 双城分开评估；可先街铺精品再 Mall |
| 科威特 | Avenues Prestige 优先；360 仅 Pop-up |
| 巴林 | Marassi（跨境）+ Moda（本国）分工，缺一需书面理由 |
| 阿曼 | 与 Mistal/Khimji 同场加分 |

## 8. 步骤

1. 列出主候选 ≤3 个地址  
2. 实地填评分表（照片：门头、动线、邻居、后台）  
3. 记录租金报价（USD）并换算 RMB（×7.2 或当期汇率）  
4. Analyst 算加权分  
5. BD Lead 定主店/备选  
6. 输出书面确认请求给招商/业主

## 9. 产出物

- 完成的选址评分表（每址一份）  
- 一页推荐结论（主店 / 备选 / 否决原因）

## 10. 验收标准

- [ ] ≥2 个地址被评估（或唯一地址已论证无替代）  
- [ ] 主店过硬性门槛且得分 ≥3.5  
- [ ] 照片与租金附件齐全

## 11. 异常分支

| 情况 | 动作 |
|------|------|
| 全场不得独立精品 | 伊朗可先 SIS 验证（Tehran Watch 模式），设 6 个月独立店里程碑 |
| 租金远超模型 | 回 SOP-06 重算；盈亏平衡 >10 台/月则升级审批 |
| 邻居全空 | 降权或否决；除非 UHNWI 街区证据极强 |
