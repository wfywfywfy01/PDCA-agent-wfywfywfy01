# SOP-08 节日档期备货

## 1. 目的

对齐中东礼品高峰，避免总部直售「有单无战役」的问题。

## 2. 触发

各国第一峰前 **6–8 周**自动启动；或代理申请档期支持时。

## 3. 角色

国别 BD（统筹）· 代理（本地执行）· 供应链（备货）· 总部市场（礼盒/刻字）

## 4. 输入

- 本年伊斯兰历 / 波斯历对照  
- 参数表产品结构（AGENT Q / ALPHAFOLD / SIGNATURE S）  
- 门店库存与在途

## 5. 各国档期权重（第一峰优先）

| 国家 | 第一峰 | 第二峰 | 第三峰 |
|------|--------|--------|--------|
| 伊朗 | Nowruz（约 3/20） | Yalda（12 月） | 进口商周年促 |
| 伊拉克 | Eid al-Fitr | Eid al-Adha | 埃尔比勒 Nowruz |
| 科威特 | Ramadan 末 + Eid | Eid al-Adha | 国庆 2/25–26 |
| 巴林 | 沙特周末（全年）+ Eid | Ramadan 末 | 国庆 12 月 |
| 阿曼 | Eid al-Fitr | Eid al-Adha | 国庆 11/18 |

**全局最大档：** Ramadan 后两周 → Eid al-Fitr（海湾 + 伊拉克巴格达）

## 6. 步骤（倒推）

| 时点 | 动作 |
|------|------|
| T-8 周 | 定主题（礼品/身份/限量）；预估台数 = 当月台阶 × 1.2–1.5 |
| T-6 周 | 下单备货；确认礼盒、刻字、成对销售政策 |
| T-4 周 | 内容与 Mall 活动档期锁定；KOL 排期 |
| T-2 周 | 到货质检；销售话术强化礼品场景 |
| T-0～高峰 | 海湾可测夜间 9–11pm 促销窗口；每日库存看板 |
| T+1 周 | 复盘：礼品占比、断货 SKU、下一峰调整 |

## 7. 产品映射（默认主推）

| 场景 | SKU 侧重 |
|------|----------|
| Eid / 政企礼品 | AGENT Q、ALPHAFOLD 礼盒 |
| 身份/限量 | SIGNATURE S、编号款（阿曼可测） |
| 入门伴手 | QUANTUM / 政策允许的礼品组合 |

## 8. 产出物

- 档期作战单（主题、SKU、台数、活动、负责人）  
- 备货 PO / 调拨单  
- 复盘一页纸

## 9. 验收标准

- [ ] 第一峰前 6 周已启动  
- [ ] 备货台数有台阶依据  
- [ ] 礼盒/刻字能力确认  
- [ ] 复盘完成并归档

## 10. 异常分支

| 情况 | 动作 |
|------|------|
| 伊朗局势导致 Nowruz 萎缩 | 降备货；加强线上与私域；不按历史峰值压货 |
| 物流延误 | 先保礼盒主力 SKU；限量款可预售 |
| 代理不做节日运营 | 计入考核；BD 介入联合 Mall 活动 |
