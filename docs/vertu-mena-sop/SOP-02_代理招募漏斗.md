# SOP-02 代理招募漏斗

## 1. 目的

从 1,000 人池筛到可签独代/核心代理的 1–2 家候选人。

## 2. 适用范围

五国任一市场启动代理招募；或现有代理不合格需补签。

## 3. 角色

| 角色 | 职责 |
|------|------|
| BD Lead | 漏斗阶段晋级审批 |
| 国别 BD | 触达、跟进、约谈 |
| Sana | 伊朗波斯语文案与培训素材 |
| 本地顾问 | 伊朗尽调与引荐 |

## 4. 输入

- SOP-01 产出的 1000 人表
- [`templates/T01_触达邮件模板.md`](templates/T01_触达邮件模板.md)
- [`tables/01_参数与目标表.md`](tables/01_参数与目标表.md)（谈目标时引用）

## 5. 漏斗数学（默认假设）

| 阶段 | 每国数量 | 说明 |
|------|----------|------|
| 储备触达池 | 1,000 | SOP-01 |
| 有效回复（~1%） | ≥10 | WhatsApp/邮件有效回复 |
| 深度谈判 | ≥5 | 已见面或 ≥30min 视频 + 商业条件讨论 |
| 签约独代/核心 | 1–2 | MOU 或独家谈判权 |

## 6. 步骤

### 6.1 远程触达（W1–W3）

| 周 | 目标 | 动作 | 产出 |
|----|------|------|------|
| W1 | 累计触达 200/国 | 精准邮件 40 封/国；LinkedIn | 触达日志 |
| W2 | 累计 600/国 | WhatsApp / IG DM；商会名单 | 每国回复 ≥6 |
| W3 | 累计 1,000/国 | 电话；引荐；伊朗顾问介绍 | **每国谈判对象 ≥5** |

**跟进节奏（单人）：** D0 邮件 → D3 WhatsApp → D7 LinkedIn → D14 电话 → D21 商会引荐

### 6.2 必须当面 vs 可线上

| 必须当面（出差前可先视频） | 可线上先行 |
|----------------------------|------------|
| Mall 招商、腕表/珠宝 Owner、汽车集团 GM、家族企业 | 3C 进口商初筛、KOL、华商破冰 |
| 签约尽调、看店选址 | Email / LinkedIn / WhatsApp |

### 6.3 深度谈判必问清单（晋级用）

1. 是否已有 Cartier / IWC / 高端 3C 运营经验？  
2. 能否承担 80㎡+ 精品店（试机+定制+贵宾室）？  
3. 是否具备基础换屏/换电售后？  
4. 资金与换汇/分期能力（伊朗/伊拉克必问）？  
5. 目标落位是否认同参数表基准档（非拍脑袋）？  
6. 伊拉克：是否接受先精品后第二城，不做多品牌稀释附属？

### 6.4 代理画像优先级（快速打分）

| 画像 | 优先级 |
|------|--------|
| 已有 IWC/Cartier 运营能力的零售集团 | T1 |
| Mistal / Khimji 级腕表运营商（阿曼） | T1 |
| 本土 3C/家电集团（B&O 路径） | T1–T2 |
| 纯礼品集合店（Haditi 类） | 仅作参照，一般不签为唯一主代理 |
| 无售后、无门店、纯炒货 | 淘汰 |

## 7. 产出物

- `Pipeline_{国家}.xlsx`（阶段：触达/回复/谈判/MOU/签约/淘汰）
- 每国 Top5 谈判一页纸（公司、能力、落位意向、风险）
- 通过者进入 SOP-03

## 8. 验收标准

- [ ] 触达 ≥1,000（或 W3 前已达）  
- [ ] 有效回复 ≥10  
- [ ] 深度谈判 ≥5  
- [ ] 至少 1 家进入「可出差闭环」状态  
- [ ] 淘汰原因已记录

## 9. 异常分支

| 情况 | 动作 |
|------|------|
| 回复率 <0.5% | 检查文案语言/身份背书；加当面引荐比例 |
| 5 家谈完无 T1 | 回 SOP-01 补腕表/珠宝/Mall 招商 |
| 候选人超时要 2× 迪拜目标 | 用参数表驳回；伊朗强调 Safiran 并轨 |
| 仅有囤货型小 B（伊拉克 HQ 教训） | 不签独代；可作临时出货渠道 |
