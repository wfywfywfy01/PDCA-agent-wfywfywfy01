# SOP-10 总部直售边界

## 1. 目的

防止总部直售挤占独代、重复「有需求但卖不动」的路径。

## 2. 背景结论（执行依据）

总部五国直售合计约 **197 万/年（53 客 / 204 台）**，约为迪拜独代 1,000 万的 1/5：

- 证明需求存在，证明模式错误  
- 伊拉克 6 客 86 台 = 小 B 囤货，不作零售成功指标  
- 伊朗盘面已被 Safiran 类代理占据  

## 3. 触发

任何人提「总部直接卖五国终端 / 再开一批 HQ 客户」时。

## 4. 角色

BD Lead（批准例外）· 销售运营（拦截）· 财务（订单标记）

## 5. 允许的总部直售（白名单）

| # | 场景 | 条件 |
|---|------|------|
| 1 | 代理招募前样品 / Demo | 数量受限，不走零售价放量 |
| 2 | 无代理城市的临时 IG 引流 | 必须标注「即将授权本地代理」；代理签约后 30 日内移交线索 |
| 3 | 合同明确保留的特殊政企单 | BD Lead 书面批准，且不破坏独代权益 |

## 6. 禁止的总部直售（黑名单）

| # | 场景 |
|---|------|
| 1 | 在已签约独代国家持续发展终端零售客户 |
| 2 | 以「客均十几台」囤货型小 B 充当市场成功 |
| 3 | 无本地售后承诺的高客单远程成交（默认禁止） |
| 4 | 用总部直售数据替代代理 Sell-in 考核 |

## 7. 步骤（接到直售需求时）

1. 判断国家是否已有独代/独家谈判权  
2. 若有 → 转介代理；HQ 不接单（除非白名单 #3）  
3. 若无 → 仅可走白名单 #1/#2，并启动 SOP-01/02  
4. 订单系统标记 `HQ_EXCEPTION` + 审批人  
5. 月报披露 HQ 例外单数量，防止静默膨胀

## 8. 产出物

- 例外审批单  
- 月度 HQ vs 代理 Sell-in 对照表

## 9. 验收标准

- [ ] 已签约国 HQ 零售单为 0（或仅有已批例外）  
- [ ] 临时线索在签约后 30 日内完成移交  
- [ ] 伊拉克类囤货订单不计入「零售健康」KPI

## 10. 异常分支

| 情况 | 动作 |
|------|------|
| 大客户点名只要总部 | 联合代理三方签约或书面利润分配 |
| 代理长期断供 | 可启动临时 HQ 供应，同时启动换代招募 |
| 业务坚持放量直售 | 升级至区域负责人；附本章背景数据 |
