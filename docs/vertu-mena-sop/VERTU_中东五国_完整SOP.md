## 1. 总则与主流程

### 1.1 一句话目标

五国全部转为「独代 Sell-in」模式：签对代理、落对商场，成熟期年 Sell-in **2,940–4,200 万 RMB**（基准档）。

### 1.2 端到端主流程

```
建名单(01) → 触达谈判(02) → 出差闭环(03)
  → 选址(04) → 定目标签约(05) → 开店测算(06)
  → 社媒(07) + 节日备货(08) + 售后(09)
```

总部直售仅按 SOP-10 执行，不得替代独代合同。

### 1.3 SOP 清单速查

| 编号 | 名称 | 优先级 | 触发 | 产出 |
|------|------|--------|------|------|
| 01 | 千人名单扩盘 | P0 | 触达池 <1000 | 去重后 1000 人表 |
| 02 | 代理招募漏斗 | P0 | 新开一国 / 补签 | 谈判短名单 + MOU |
| 03 | 出差闭环 | P0 | 每国 ≥5 谈判对象就绪 | 店址确认 + Term Sheet |
| 04 | 落位选址 | P1 | 看店 / 谈招商 | 主店评分表 |
| 05 | Sell-in 目标设定 | P1 | 写合同 / 季度复盘 | 三档 KPI + 月度台阶 |
| 06 | 单店月度 P&L | P1 | 开店前 / 每月经营会 | 盈亏平衡 + 月净利 |
| 07 | 社媒获客 | P2 | 代理签约后 | 内容日历 + 周报 |
| 08 | 节日档期备货 | P2 | 大节前 6–8 周 | 备货与活动清单 |
| 09 | 售后与跨境履约 | P2 | 出货 / 客诉 | 维修 SLA + 结算路径 |
| 10 | 总部直售边界 | P3 | 有人要求总部直卖 | 允许/禁止清单 |

### 1.4 五国成功总标准

| 里程碑 | 标准 |
|--------|------|
| 名单 | 每国触达池 ≥1,000（去重） |
| 谈判 | 每国深度谈判 ≥5 |
| 出差 | 每国 ≥1 份 MOU/独家谈判权 + 主店址书面确认 |

| 经营 | 成熟期达附录 A 基准档；Y1 ≥ 保守档（Kc≈0.55） |

## 4. SOP-02 代理招募漏斗

### 4.1 目的

从 1,000 人池筛到可签独代/核心的 1–2 家。

### 4.2 触发

新开一国或现有代理不合格需补签。

### 4.3 漏斗数学

| 阶段 | 每国数量 |
|------|----------|
| 储备触达池 | 1,000 |
| 有效回复（~1%） | ≥10 |
| 深度谈判 | ≥5 |
| 签约独代/核心 | 1–2 |

### 4.4 远程触达（W1–W3）

| 周 | 目标 | 动作 | 产出 |
|----|------|------|------|
| W1 | 触达 200/国 | 精准邮件 40 封/国；LinkedIn | 触达日志 |
| W2 | 累计 600/国 | WhatsApp / IG DM；商会 | 每国回复 ≥6 |
| W3 | 累计 1,000/国 | 电话；引荐 | **谈判对象 ≥5** |

**单人跟进节奏：** D0 邮件 → D3 WhatsApp → D7 LinkedIn → D14 电话 → D21 商会引荐

### 4.5 当面 vs 线上

| 必须当面 | 可线上先行 |
|----------|------------|

## 6. SOP-04 落位选址

### 6.1 目的

统一评分选主店，避免「最大 Mall = 最好」。

### 6.2 硬性门槛（任一不满足 → 不进主店候选）

1. 面积 ≥80㎡（伊拉克首店 80–120㎡）
2. 可做品牌独立门头或清晰精品形象
3. 邻居含腕表/珠宝/硬奢至少一类（或可证 UHNWI 动线）
4. 租金可解释或代理书面接受超支
5. 科威特主店不得选 Al Hamra Tower
6. 阿曼优先 Mall of Oman L3 或 Qurum

### 6.3 评分维度（1–5，加权）

| 维度 | 权重 |
|------|------|
| UHNWI / 高端客群密度 | 25% |
| 奢侈品邻居浓度 | 20% |
| 客流质量（非唯总量） | 15% |
| 可达性与停车/礼宾 | 10% |
| 租金与合同弹性 | 15% |
| 售后/仓储可行性 | 10% |
| 代理运营匹配 | 5% |

**通过线：** 加权 ≥3.5 且硬性门槛全过。主店取最高分；备选留 1 个。

### 6.4 分国快速规则

| 国家 | 规则 |
|------|------|
| 伊朗 | 3 城覆盖 > 同城多开；第 4 店默认不批 |
| 伊拉克 | 双城分开评；可先街铺精品再 Mall |
| 科威特 | Avenues Prestige 优先；360 仅 Pop-up |
| 巴林 | Marassi（跨境）+ Moda（本国），缺一需书面理由 |
| 阿曼 | 与 Mistal/Khimji 同场加分 |

### 6.5 步骤

1. 列出主候选 ≤3 个地址
2. 实地填评分表（门头/动线/邻居/后台照片）
3. 记录租金 USD → RMB（×7.2 或即期）
4. Analyst 算加权分
5. BD Lead 定主店/备选
6. 向招商/业主发书面确认请求

### 6.6 验收

- [ ] ≥2 址评估（或唯一址已论证）
- [ ] 主店过门槛且得分 ≥3.5
- [ ] 照片与租金附件齐全

### 6.7 异常

| 情况 | 动作 |
|------|------|
| 无法独立精品 | 伊朗可先 SIS，设 6 个月独立店里程碑 |
| 租金致平衡点 >10 台/月 | 回 SOP-06；升级审批 |
| 邻居全空 | 降权或否决 |

评分表见 [附录 C.2](#c2-选址评分表)。

## 7. SOP-05 Sell-in 目标设定

### 7.1 目的

把附录 A 基准档写成可进合同的月度台阶。

### 7.2 步骤

1. **锁定 ASP**：默认 ¥24,939；乐观结构可并列 ¥26,200，合同计价仍用默认。
2. **取成熟基准台数**：查附录 A 分国区间。
3. **套 Kc**：
   - 合同成熟目标 = 基准档（Kc=1.0）
   - Y1 考核 = 基准 × 0.4–0.6
   - 预警线 = 保守档（基准 × 0.55）
4. **换算**：`月 Sell-in（万）= 台数 × ASP ÷ 10,000`
5. **写月度台阶**：

| 阶段 | Kc 参考 |
|------|---------|
| 0–6 月 | ~0.45–0.55 |
| 7–12 月 | ~0.65–0.75 |
| 12 月后 | 1.0 |

6. **伊朗专规**：成熟全国 30–40 台 = Safiran 并轨 + 官方增量；**禁止**写「2× 迪拜」或「额外再造 60–80 台」。
7. **合计校验**：五国成熟约 98–140 台/月；远超则回头查店数/Km。
8. **BD Lead 签字** 后方可进合同。

### 7.3 伊朗合同台阶示例（他国按同比例缩放）

| 阶段 | 月 Sell-in | 月台数 |
|------|------------|--------|
| 0–6 月 | 40–55 万 | 16–22 |
| 7–12 月 | 55–75 万 | 22–30 |
| 成熟 | 75–100 万 | 30–40 |

### 7.4 验收

- [ ] 合同主目标 = 基准档（非乐观）
- [ ] Y1 ≤ 基准且落在合理区间
- [ ] 伊朗含并轨表述
- [ ] 台数与金额可互相还原（误差 <1 台）

### 7.5 异常

| 情况 | 动作 |
|------|------|
| 代理只接保守档 | 可签，资源按保守配；达基准再加店 |
| Y1 < 保守档 | **先修渠道与落位**，不降 ASP、不加店 |
| 总部要抬乐观档 | 仅作激励条款，不作违约底线 |

## 8. SOP-06 单店月度 P&L

### 8.1 口径（不得混比）

1. 按**月**测算
2. 装修 = 总额 ÷ **24**
3. 代理毛利 = **RRP×35% 或 RRP×1.2**，不用 Sell-in×25%
4. 总部看 Sell-in；代理看月净利 — 分列

### 8.2 公式

```
月毛利 = 月出货量 Q × 单台混合毛利（默认 ¥15,347）
月固定成本 = 月租 + 月人力 + 月运营杂费 + 装修÷24
月净利 = 月毛利 − 月固定成本
盈亏平衡台数 = 月固定成本 ÷ 单台混合毛利
```

### 8.3 红绿灯

| 状态 | 条件 |
|------|------|
| 红 | Q < 盈亏平衡 |
| 黄 | 盈亏平衡 ≤ Q < 成熟下限 |
| 绿 | Q ≥ 成熟下限 |

多店国家：先单店再全国加总。

## 12. SOP-10 总部直售边界

### 12.1 背景（执行依据）

### 12.2 白名单（允许）

| # | 场景 | 条件 |
|---|------|------|
| 1 | 代理招募前样品/Demo | 数量受限，不零售放量 |

| 3 | 合同保留的特殊政企单 | BD Lead 书面批准且不破坏独代权益 |

1. 已签约独代国家持续发展 HQ 终端零售

### 12.4 处理步骤

1. 判断该国是否已有独代/独家谈判权
2. 有 → 转介代理（除非白名单 #3）
3. 无 → 仅白名单 #1/#2，并启动 SOP-01/02
4. 订单标记 `HQ_EXCEPTION` + 审批人
5. 月报披露 HQ 例外单，防静默膨胀

### 12.5 验收

- [ ] 已签约国 HQ 零售单为 0（或仅已批例外）
- [ ] 临时线索签约后 30 日内移交
