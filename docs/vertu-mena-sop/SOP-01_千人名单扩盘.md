# SOP-01 千人名单扩盘

## 1. 目的

每国建成可触达的 1,000 人储备池，供 SOP-02 漏斗使用。

## 2. 适用范围

伊朗 / 伊拉克 / 科威特 / 巴林 / 阿曼；新建或池内有效联系人 <1,000 时触发。

## 3. 角色

| 角色 | 职责 |
|------|------|
| BD Lead | 验收、去重规则 |
| 国别 BD（阿语/Sana） | 执行 D1–D7 |
| Analyst | 字段清洗、去重 |

## 4. 输入

- Seed CSV（Master_Seed80 或 Oman_Seed100）
- 腕表珠宝扩展 CSV（如有）
- 本表字段模板（见下）

## 5. 步骤（每国 7 天复用）

| 天 | 动作 | 工具 | 当日净增目标 |
|----|------|------|--------------|
| D1 | 导入 Seed | Excel | 基础盘 76–100 |
| D2 | Mall 官网 Store Directory 扫商户 | Chrome + 表 | +150 |
| D3 | LinkedIn Sales Navigator：CEO/Owner/GM | LinkedIn | +200 |
| D4 | Instagram 地标 hashtag（如 #luxury_tehran） | IG | +150 |
| D5 | 商会/展会/使馆名单 | 官网 PDF | +100 |
| D6 | Google Maps：「watch shop」「mobile distributor」 | Maps | +200 |
| D7 | 去重 + 补邮箱 | Hunter / 官网 Contact | **合计达 1,000** |

### 必填字段

`国家, 类别, 公司, 联系人, 职位, 手机/WhatsApp, 邮箱, LinkedIn, IG, 来源日, 来源渠道, 优先级(T1/T2/T3), 备注`

### 人群结构目标占比（验收用）

| 类别 | 占比 |
|------|------|
| 3C 分销/进口商 | 25% |
| 高端腕表零售 | 15% |
| 高端珠宝 | 12% |
| 奢侈品多品牌集团 | 5% |
| Mall 招商 | 8% |
| 超豪汽车经销商 | 5% |
| 华商/商会 | 10% |
| 社媒 KOL | 8% |
| 酒店礼宾 | 4% |
| 现有渠道推荐 | 3% |
| 其他（律所/物流/维修） | 5% |

分国「去哪里找」详见战略报告第八章；阿曼优先 Mistal / Khimji。

## 6. 产出物

- `VERTU_MENA_{国家}_Pool_1000.csv`（去重后 ≥1,000）
- 当日日志：来源渠道 × 新增数

## 7. 验收标准

- [ ] 去重后 ≥1,000  
- [ ] T1 ≥80（可优先谈判）  
- [ ] 含邮箱或 WhatsApp 的有效触达率 ≥60%  
- [ ] 3C + 腕表珠宝合计 ≥35%

## 8. 异常分支

| 情况 | 动作 |
|------|------|
| D7 仍不足 1,000 | 加一轮 D2+D6；放宽 Maps 关键词 |
| 某类占比严重偏离 | 定向补该类，不盲目加 KOL |
| 伊朗信息难抓 | 加德黑兰顾问引荐 + Telegram 数码频道 |
