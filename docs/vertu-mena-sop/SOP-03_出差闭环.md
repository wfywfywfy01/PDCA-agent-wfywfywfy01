# SOP-03 出差闭环

## 1. 目的

在约 4 周出差窗口内，完成每国「代理意向 + 主店址」双闭环。

## 2. 触发条件

SOP-02 达标：目标国深度谈判对象 ≥5，且至少 1 家愿意当面看店/谈条件。

## 3. 角色

| 角色 | 职责 |
|------|------|
| 区域 BD Lead | 全程带队、签 MOU |
| Sana | 伊朗段 |
| 德黑兰顾问 | 伊朗陪同、尽调 |
| Luxury Analyst | 选址记录、租金核对 |
| 海湾阿语 BD | 科/巴段主谈 |

## 4. 输入

- Top5 谈判名单  
- [`tables/02_分国落位速查.md`](tables/02_分国落位速查.md)  
- [`SOP-04_落位选址.md`](SOP-04_落位选址.md) 评分表  
- 空白 Term Sheet / MOU 模板

## 5. 出差周计划（标准顺序）

| 周 | 国家 | 目的 | 可达成事项 | 考察重点 |
|----|------|------|------------|----------|
| W4 | 科威特 | 迁址谈判 | Avenues 招商 MOU；代理 Term Sheet | Prestige 客流、邻居、租金 |
| W5 | 巴林 | 双 Mall | Marassi+Moda 意向；Kooheji 等深度会 | 周末沙特车牌比例 |
| W6 | 伊拉克 | 双城代理 | Erbil + Baghdad 各 1 谈判闭环 | Arasat / Mansour；安全评估 |
| W7 | 伊朗 | 新代理+店址 | 德黑兰+Mashhad 选址确认；社媒培训启动 | Sam/Palladium；Ahmadabad |

**团队建议：** BD Lead + 国别专员 +（伊朗）本地顾问 + Analyst

## 6. 每日标准动作（到一国后）

1. 上午：主候选人当面会（必问清单见 SOP-02）  
2. 下午：主店址实地（按 SOP-04 打分）  
3. 傍晚：备选店或邻居品牌踩点  
4. 当晚：更新 `Trip_Log`：会见人、结论、待办、红旗风险  
5. 离境前：力争拿到 **书面意向**（邮件确认也算）

## 7. 产出物

| 产出 | 标准 |
|------|------|
| MOU / 独家谈判权 | 每国 ≥1 |
| 主店址书面确认 | Mall 招商或业主邮件/LOI |
| 选址评分表 | 主店 ≥通过线（见 SOP-04） |
| Term Sheet 草稿 | 含月度台阶（SOP-05） |
| 风险备忘 | 制裁/安全/退出成本（科威特 Al Hamra） |

## 8. 验收标准（成功标准）

- [ ] 每国 ≥1 份 MOU 或独家谈判权  
- [ ] 主店址书面确认  
- [ ] 选址评分完成且主店推荐明确  
- [ ] 合同目标与参数表基准档对齐（伊朗含 Safiran 并轨表述）  
- [ ] Trip_Log 归档

## 9. 异常分支

| 情况 | 动作 |
|------|------|
| 区域冲突/签证延误 | 缩短窗口；改视频+本地顾问代看店；启用线上 IG 销售备份 |
| 伊拉克安全升级 | Erbil 优先；巴格达可延后 |
| 招商拒 VERTU | 启用备选 Mall；科威特可评估 360 Pop-up 过渡 |
| 代理谈崩 | 立即启动 Top5 中下一家；不空窗超过 10 天 |
| Al Hamra 退出成本不清 | 先测算再签新租约 |
