## 端到端主流程

```
建名单(SOP-01) → 触达谈判(SOP-02) → 出差闭环(SOP-03)
    → 选址(SOP-04) → 定目标签约(SOP-05) → 开店测算(SOP-06)
    → 社媒运营(SOP-07) + 节日备货(SOP-08) + 售后(SOP-09)
```

总部直售仅按 SOP-10 边界执行，不得替代独代合同。
