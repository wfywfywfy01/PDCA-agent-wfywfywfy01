# SOP-09 售后与跨境履约

## 1. 目的

保证高客单信任链：本地可响应，跨境可结算，制裁/安全风险可控。

## 2. 触发

代理尽调阶段；首批发货前；客诉/寄修发生时。

## 3. 角色

迪拜售后（GCC 中枢）· 代理（一线）· 供应链 · BD Lead（升级）· 伊朗顾问（尽调）

## 4. 网络分工

| 区域 | 售后路径 |
|------|----------|
| GCC（科/巴/阿） | 优先迪拜 Meysiam 中心辐射 |
| 伊朗 | Safiran 或新代理本地 backup；迪拜转运 |
| 伊拉克 | 本地基础维修 + 迪拜/伊朗 backup |

**代理硬性能力：** 签约前须具备或承诺 **基础换屏 / 换电**。

## 5. 步骤

### 5.1 签约前尽调（必做）

1. 检查维修工位/备件柜/工程师  
2. 确认结算路径：本地货币 / 人民币 / 黄金等（伊朗敏感）  
3. 确认物流：迪拜转运可行性与时效  
4. 伊拉克：双城是否分仓、安全运输方案  
5. 输出《履约尽调表》红黄绿

### 5.2 出货前

1. 激活保修登记流程（当地语言）  
2. 明确 SLA：本地基础件 vs 寄修迪拜/中国  
3. 告知客户预期：寄修周期可能 **7–21 天**，须在销售话术披露

### 5.3 客诉处理

1. 代理 24h 内响应  
2. 可本地解决 → 本地关单  
3. 不可本地 → 建单寄修，同步客户节点  
4. 超 SLA → 升级 BD Lead + 迪拜售后

## 6. 风险应对（摘录）

| 风险 | 应对 |
|------|------|
| 伊朗制裁/换汇 | 迪拜转运；合规结算；顾问尽调 |
| 伊拉克安全 | 双城分代理/分仓；Erbil 优先保障 |
| 区域冲突 | 缩短出差；强化线上成交与远程指导 |
| 科威特迁址 | 同步测算旧店退出成本 |

## 7. 产出物

- 履约尽调表  
- 保修/寄修 SLA 一页纸（当地语言）  
- 月度售后工单汇总

## 8. 验收标准

- [ ] 代理基础维修能力达标或有时限整改计划  
- [ ] SLA 已向销售团队培训  
- [ ] 结算与物流路径书面确认  
- [ ] 高风险国完成尽调绿灯或附条件黄灯

## 9. 异常分支

| 情况 | 动作 |
|------|------|
| 代理拒做任何维修 | 不签独代或强制绑定第三方授权点 |
| 寄修时效持续 >21 天 | 增加迪拜周转备机/备件 |
| 结算路径违规嫌疑 | 立即暂停出货，升级合规 |
