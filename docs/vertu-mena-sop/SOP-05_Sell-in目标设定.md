# SOP-05 Sell-in 目标设定

## 1. 目的

把参数表基准档写成可进合同的月度台阶，防止拍脑袋要量。

## 2. 触发

起草 Term Sheet / 代理合同；或每季度业绩复盘调档。

## 3. 角色

BD Lead（拍板）· Analyst（测算）· 国别 BD（与代理对齐）

## 4. 输入

- [`tables/01_参数与目标表.md`](tables/01_参数与目标表.md)  
- 店数与落位结论（SOP-04）  
- 伊朗：Safiran 现状台数（用户确认值）

## 5. 步骤

1. **锁定 ASP**：默认 ¥24,939；若产品结构明确偏 GCC 精品，可并列乐观 ASP ¥26,200，合同仍以默认 ASP 计价。  
2. **取成熟基准台数**：查参数表分国区间中值或约定上下限。  
3. **套 Kc**：  
   - 合同成熟目标 = 基准档（Kc=1.0）  
   - Y1 考核 = 基准 × 0.4–0.6（建议写清区间）  
   - 预警线 = 保守档（基准 × 0.55）  
4. **换算金额**：`月 Sell-in（万）= 台数 × ASP ÷ 10,000`  
5. **写月度台阶**（示例结构）：  

| 阶段 | Kc 参考 | 动作 |
|------|---------|------|
| 0–6 月 | ~0.45–0.55 | 开店磨合 / 并轨 |
| 7–12 月 | ~0.65–0.75 | 爬坡 |
| 12 月后 | 1.0 | 成熟基准 |

6. **伊朗专规**：  
   - 成熟全国 30–40 台 = Safiran 并轨 + 官方增量  
   - 合同措辞禁止「额外再造 60–80 台」或「2× 迪拜」  
7. **五国合计 sanity check**：成熟合计应约 98–140 台/月；若合计远超，回头查店数/Km。  
8. **BD Lead 签字** 后方可进合同。

## 6. 产出物

- `Target_Card_{国家}_{版本}.md`：保守 / 基准 / 乐观 + 月度台阶  
- Term Sheet「销售目标」条款草稿

## 7. 验收标准

- [ ] 合同主目标 = 基准档（非乐观档）  
- [ ] Y1 目标 ≤ 基准且 ≥ 保守档下限的合理子集  
- [ ] 伊朗含并轨表述  
- [ ] 台数与金额双向可还原（用 ASP 反算误差 <1 台）

## 8. 异常分支

| 情况 | 动作 |
|------|------|
| 代理只肯接保守档 | 可签约，但落位与 BD 资源按保守配置；复盘达基准再加店 |
| Y1 实际 < 保守档 | **优先修渠道与落位**，不降 ASP、不加店 |
| 总部要求抬到乐观档 | 仅作激励条款（bonus），不作违约底线 |
