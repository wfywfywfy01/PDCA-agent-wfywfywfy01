# SOP-06 单店月度 P&L

## 1. 目的

按月评估代理门店盈亏，开店前验证经济模型，开店后做经营会。

## 2. 触发

开店决策前；每月经营复盘；租金/人力重大变更时。

## 3. 角色

Analyst（编制）· BD Lead（审批）· 代理（提供实销）· 售后（杂费校准）

## 4. 输入

- [`tables/01_参数与目标表.md`](tables/01_参数与目标表.md) §6  
- 实际：月出货台数、租金、人力、装修总额  
- 毛利假设：混合 ¥15,347/台（或按实际 RRP/溢价拆分）

## 5. 口径规则（不得改口径混比）

1. 按**月**测算，不按年摊口头约  
2. 装修 = 总额 ÷ **24** 计入月固定成本  
3. 代理毛利用 **RRP×35% 或 RRP×1.2**，**不用** Sell-in×25%  
4. 总部看 Sell-in；代理看月净利 — 两表分列

## 6. 步骤

1. 取月出货量 Q（台）  
2. 月毛利 = Q × 单台混合毛利  
3. 月固定成本 = 月租 + 月人力 + 月运营杂费 + 装修÷24  
4. 月净利 = 月毛利 − 月固定成本  
5. 盈亏平衡台数 = 月固定成本 ÷ 单台混合毛利  
6. 对照参数表「成熟月台数」与「盈亏平衡」：  
   - Q < 盈亏平衡 → 红灯  
   - 盈亏平衡 ≤ Q < 成熟下限 → 黄灯  
   - Q ≥ 成熟下限 → 绿灯  
7. 多店国家（伊朗/巴林/伊拉克）：先单店再全国加总

## 7. 样例（科威特 17 台/月 · 校验用）

| 项目 | 月金额 RMB |
|------|------------|
| Sell-in（总部） | ~424,963 |
| 毛利（17×15,347） | 260,899 |
| 固定成本 | −111,813 |
| 净利 | **+149,086** |

## 8. 产出物

- 月度 P&L 表（单店 + 全国）  
- 红绿灯结论 + 3 条行动建议

## 9. 验收标准

- [ ] 使用混合毛利或实际拆分，且注明口径  
- [ ] 装修按 24 月摊  
- [ ] 盈亏平衡台数已计算  
- [ ] 红灯必须带「落位/人效/产品结构」之一的整改动作

## 10. 异常分支

| 情况 | 动作 |
|------|------|
| 固定成本上升导致平衡点 >10 台 | 重谈租金或缩面积；升级 BD Lead |
| 连续 2 月红灯 | 触发选址复审（SOP-04）+ 目标复审（SOP-05） |
| 代理要求改回年口径 | 拒绝；可另附年汇总，月表仍为主表 |
