# Omega 会议情景卡

## 场景范围

| 分类 | 情景卡 | 这场会要练出的结果 |
| --- | --- | --- |
| 合作 | 破冰会议 | 介绍已核实的品牌与产品，摸清代理背景、当地市场、需求和下一次沟通 |
| 合作 | 方案推进会议 | 把首次沟通的痒点、痛点和定位诉求转成可验证的合作方案 |
| 合作 | 试订单推进 | 核对折扣、营销、售后、开店、交货和物流条件及书面依据 |
| 培训 | 合作启动培训 | 按本次命题培训品牌、文化、产品、工具、销售、陈列或铺货，并让学员复述 |
| 培训 | 终销培训 | 演练终销对话、公司版门店五件套和社媒获客动作 |
| 培训 | 新品培训 | 讲清新品定位、与旧品的可核实差异、演示和常见问题 |
| 经营 | 市场营销支持会议 | 确认目标、渠道、资源、审批、责任和复盘指标 |
| 经营 | 店铺周会 | 根据终销、库存和店铺执行数据决定一项下周动作 |
| 经营 | 店铺月会 | 分析趋势、库存结构和门店差异，决定下月资源与计划 |
| 经营 | 开店准备会议 | 核对选址客群、陈列、培训、铺货及开业前置条件 |
| 经营 | 补货复购会议 | 用动销与库存判断补货结构、节奏和风险 |
| 经营 | 售后问题协调会议 | 核实问题、政策、责任、升级路径与回复时间 |
| 临时 | 临时自定义会议 | 填写本次命题后开始练习或导入真实会议复盘 |

原有八张专项练习卡仍可在「专项」分类使用。卡片都是训练设定，不代表 VERTU 已批准的价格、政策、收益或交期。没有正式资料时，对手应要求核对，复盘也不能把假设写成事实。

## 临时资料

选择任意会议卡后，展开「本次命题与资料」：可写命题、选推荐主题、上传最多 3 份 TXT、MD、CSV、PDF、DOCX、PPTX 或 XLSX。单份不超过 5 MB，当前每份只使用提取文字的前 1800 字；上传后可检查和修改提取结果。扫描图片 PDF 无法提取文字时会报错，不会假装已读懂。

每份资料可标记为「会议资料」「培训内容」「会议命题」，并选择「模拟对手与教练」或「仅复盘教练」。原文件不保存到长期知识库；提取文字随本场场景快照保存，供本场练习、暂停教练和复盘使用。它不会写入团队预设，也不会作为长期档案建议的输入。按照现有团队权限，同组有权限的成员能查看本场记录。

培训与门店经营会议有对应的模拟参会角色。培训评分将「让步」标记为不适用，门店周会/月会更看重数据核对。所有评分仍须引用本场原话；证据不足时不强行给总分。

## 验收点

1. 每一类会议卡都能选择、修改命题、上传资料，并启动文字或已配置的实时语音练习；临时会议没有命题不能开练。
2. 资料的用途、受众和提取文字进入本场冻结快照，不改变团队预设；仅教练资料不进入模拟参会人的提示词。
3. PDF、Office 和文本资料能提取文字；错误格式、空文件、超限文件给出可读错误。长文明确显示截短提示。
4. 结束后的报告基于原话打分，培训/经营评分项与该会议适配，主管仍可按有证据的卡点安排下一轮。
5. 手机 390×844 首屏能看到第一张卡的开练按钮，所有分类和资料入口可操作，无横向页面溢出。
